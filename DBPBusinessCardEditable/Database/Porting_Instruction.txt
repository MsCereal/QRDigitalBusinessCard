DBP DIGITAL BUSINESS CARD (eCard) - PORTING INSTRUCTION (UAT)
=============================================================

Package contents
  eCard\                     the application (copy this folder to the web server)
  Porting_Instruction.txt    this file

Database: none needed. All employee cards are saved in ONE file on the web server
(C:\inetpub\eCard_data\bizcard.db). The file is created automatically on the first visit.
No database server, no SQL script and no database login are required.


A. BACKUP
   Not applicable at this time (first installation).


B. PORTING

   SYSTEM ADMIN  -  Web server 172.16.64.19
   ----------------------------------------
   Requirement (one time): the ".NET 8 Hosting Bundle" (ASP.NET Core Runtime 8.0 Hosting Bundle)
   must be installed on the server. Check: "AspNetCoreModuleV2" appears in IIS Manager > server > Modules.
   If it was just installed, restart IIS (run "iisreset" as administrator).

   1.  Remote desktop to UAT 172.16.64.19.

   2.  Copy the folder "eCard" from the package to:
           C:\inetpub\wwwroot\eCard
       (On a redeploy: stop the eCard website first, then replace the files.
        Do NOT touch C:\inetpub\eCard_data - it holds all the employee cards.)

   3.  Create these two folders (outside the app folder):
           C:\inetpub\eCard_data          the card data file (bizcard.db)
           C:\inetpub\eCard_published     published card pages

   4.  IIS Manager > Application Pools > Add Application Pool:
           Name:                     eCard
           .NET CLR version:         No Managed Code
           Managed pipeline mode:    Integrated
       Then select eCard > Advanced Settings:
           Load User Profile:        True   (keeps users signed in after a restart)

   5.  Give the app pool permission (right-click folder > Properties > Security > Edit > Add,
       type  IIS AppPool\eCard  > Check Names > OK):
           C:\inetpub\wwwroot\eCard        Read & execute
           C:\inetpub\eCard_data           Modify
           C:\inetpub\eCard_published      Modify
       Only the app pool and administrators should have access to C:\inetpub\eCard_data
       (it holds employee details).

   6.  IIS Manager > Sites > Add Website:
           Site name:          eCard
           Application pool:   eCard
           Physical path:      C:\inetpub\wwwroot\eCard
           Binding:            http, IP 172.16.64.19 (or All Unassigned), port 80
                               (use another port, e.g. 8080, if port 80 is already used)
       IMPORTANT: it must be its own WEBSITE, not an application/virtual folder
       under "Default Web Site" (the app's links start at the site root).
       Untick "Start Website immediately" (start it at step 10).

   7.  Select the eCard site > Authentication:
           Anonymous Authentication   Enabled
           Windows Authentication     Enabled
       (Windows Authentication is used for employee sign-in. If it is missing, install it:
        Server Manager > Add Roles and Features > Web Server > Security > Windows Authentication.)

   8.  Check C:\inetpub\wwwroot\eCard\web.config (Notepad as administrator):
           Database__Path             : C:\inetpub\eCard_data\bizcard.db  (leave as is)
           Publishing__PublicBaseUrl  : http://<site address>/published
                                        (e.g. http://172.16.64.19/published, or with the port
                                        if not 80: http://172.16.64.19:8080/published)
           ADMIN_KEY                  : leave empty to keep the admin console off,
                                        or set a strong password for the admin console.
       Save the file if you changed anything.

   9.  Firewall: allow inbound TCP on the site port (80 or the chosen port) on 172.16.64.19.
       (Only if the site has a name, e.g. ecard-uat.dbp.local: ask the network team for
        the DNS record pointing to 172.16.64.19.)

   10. IIS Manager > Sites > eCard > Start (right side, "Manage Website > Start").
       The file C:\inetpub\eCard_data\bizcard.db is created on the first visit to the site.

   11. Smoke test (on the server, then from a user PC):
           http://<site address>/         Welcome page appears
           http://<site address>/login    Sign In page appears
           Sign in with a Windows account, create a card, Save  -> QR page appears
           Scan the QR with a phone: the phone offers to save the contact
       If the site shows an error (HTTP 500.30 / 500.x): see "If something goes wrong".


C. BACKOUT
   Not applicable at this time (first installation).
   To remove: IIS Manager > Sites > eCard > Stop, then remove the site and the app pool,
   and the folders C:\inetpub\wwwroot\eCard, C:\inetpub\eCard_published and
   C:\inetpub\eCard_data (back up eCard_data first if the cards must be kept).


DATA BACKUP (after go-live)
   All cards are in C:\inetpub\eCard_data. To back up: stop the eCard website, copy the
   whole eCard_data folder (bizcard.db and any bizcard.db-wal / bizcard.db-shm files)
   to the backup location, then start the website again. Schedule this regularly
   (e.g. daily, outside office hours).
   To restore: stop the website, put the backed-up files back in C:\inetpub\eCard_data,
   start the website.


IF SOMETHING GOES WRONG
   - HTTP 500.19            The .NET 8 Hosting Bundle is not installed (or IIS was not restarted).
   - HTTP 500.30 / 500.x    App failed to start. Usually folder permissions: check that
                            IIS AppPool\eCard has Modify on C:\inetpub\eCard_data and
                            C:\inetpub\eCard_published (step 5).
                            To see the reason: in web.config set stdoutLogEnabled="true",
                            create the folder C:\inetpub\wwwroot\eCard\logs, restart the site,
                            read the newest file in that folder, then set it back to "false".
                            Also check Windows Event Viewer > Windows Logs > Application.
   - Sign-in fails          Windows Authentication not enabled on the site (step 7).
   - "Publish failed"       The app pool has no Modify permission on C:\inetpub\eCard_published.
